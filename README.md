# tutorials-freak-LandingPage
A responsive educational website built using HTML, CSS, and Bootstrap with modern UI .
A modern and fully responsive **e-learning landing page UI** built using **Bootstrap 5**.
This project focuses on creating a clean, structured, and mobile-first layout using Bootstrap components and utilities.

---

## 🚀 Features

* Fully responsive design (mobile-first approach)
* Modern landing page UI
* Hero section with CTA
* Course cards layout using Bootstrap grid
* Features and categories sections
* FAQ-style content layout
* Call-to-action section
* Mobile app download section with input group
* Clean footer with social links

---

## 🛠️ Tech Stack

* HTML5
* Bootstrap 5 (Grid, Utilities, Components)
* Custom CSS (for UI polish & interactions)

---

## 📂 Project Structure

* index.html
* style.css
* Images/
* README.md

---

## 🎯 Purpose

This project demonstrates **core Bootstrap skills**, including:

* Grid system usage
* Responsive layouts
* Flexbox utilities
* Bootstrap components (navbar, cards, buttons, input groups)
* Mobile-first design approach

---

## 📌 Note

This is a **static frontend project** focused on UI/UX and responsiveness.
No backend or JavaScript functionality has been implemented yet.
